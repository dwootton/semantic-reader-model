# Compaction rules audit: semantic evidence at risk

Read-only implementation audit, 2026-09-12. This note identifies what the organizer can no longer see; it does not claim that a model failed on the fixtures below. No production code or tests were changed.

The existing 11 browser regression tests pass. Ten additional synthetic HTML cases were run through the current `compactDOM` in isolated, network-blocked Chromium. Every case passed its existing encoding/provenance checks while exhibiting the losses described below. These checks intentionally do not establish semantic completeness.

## Priorities before collecting complete-hierarchy training targets

1. **Protect meaningful contents against ancestor folds, and charge ancestor folds for the contents they remove.** The budget loop protects native headings and a small set of explicit state contexts, not ordinary controls, whole forms, code, or math. Excluding an element from being a fold candidate does not prevent its ancestor from deleting it. The score penalizes a candidate that *is* a form/dialog, but not an ordinary ancestor containing that form/dialog. A synthetic `main` containing one required email field, its label, and submit button became only its `h1` plus a preview; exposed controls fell from two to zero. Another fixture lost both its entire MathML equation and its `pre` block. Both passed. Relevant code: [candidate filtering and roots](../../experiments/dom-downsampling/compact.js#L211), [priority](../../experiments/dom-downsampling/compact.js#L225), [pruning](../../experiments/dom-downsampling/compact.js#L234). Add a compact unit inventory for folded regions: control type/name/state, fieldset and table context, content-type boundaries, and source references for expansion. Apply preservation and folding cost to the affected subtree, not only the candidate tag. Whether every control is initially expanded is a separate cost decision.

2. **Retain boundaries of branching generic containers.** Structural stripping removes class/style first and then flattens every attribute-free `div`/`span` with no direct text, regardless of number of children. Two synthetic plan cards, each with a heading, price, and Choose button, became six siblings under `main` in `structure` mode. Source order survives, but card membership and candidate region boundaries do not. This does not prove the model cannot infer grouping; it makes it infer information the input originally contained. Relevant code: [attribute stripping](../../experiments/dom-downsampling/compact.js#L92), [wrapper flattening](../../experiments/dom-downsampling/compact.js#L133). Collapse unary wrappers freely; preserve a short source-referenced boundary for branching containers until a separate rule can justify removing it. Raw CSS class lists are not needed for this.

3. **Make preservation recognize semantic roles and the whole name/error relationship context.** `HEADINGS` recognizes native tags but not `[role="heading"]`; explicit exceptions omit states such as `aria-checked="mixed"`, `aria-expanded="true"`, disabled/required fields, and polite live status. The state-context traversal follows labels plus `aria-labelledby` and `aria-describedby`, but not `aria-errormessage`, `aria-details`, table header relationships, or active-descendant context. A synthetic ARIA heading was folded entirely; a middle list item containing a mixed checkbox was sampled away. Relevant code: [selectors](../../experiments/dom-downsampling/compact.js#L22), [state contexts](../../experiments/dom-downsampling/compact.js#L152), [list sampling](../../experiments/dom-downsampling/compact.js#L187). Add role-aware names and a bounded relationship closure around retained units. Decide explicitly which states are exceptions versus merely included in the compact unit inventory.

4. **Preserve relationship evidence even when one endpoint is deferred.** If any IDREF endpoint is missing, the final pass removes the *entire* relationship and exposes only the attribute name in `data-relations-deferred`. In a synthetic button with `aria-labelledby="primary detail"`, the primary label remained visible and the detail was folded. The button lost both associations. This successfully prevents dangling ordinary HTML relationships, but removes useful surviving evidence and does not give the model the missing target reference. Fragment links lose their relationship earlier as described below. Relevant code: [relationship pruning](../../experiments/dom-downsampling/compact.js#L251). Represent observed and deferred relation edges explicitly with stable source references; do not imply a fully resolved accessible name when one component is missing.

5. **Do not validate protected context against an already shortened baseline.** State contexts are identified before excerpting, but `expectedStateContext` is recorded after excerpting and list sampling. A synthetic alert consisting of a long background paragraph followed by “Do not submit another payment.” lost that final instruction at the 180-character limit, while `stateContextPreserved` stayed true. The output correctly carried `data-excerpt`; the check is therefore a post-excerpt folding check, not preservation of the original alert. Relevant code: [excerpting](../../experiments/dom-downsampling/compact.js#L167), [baseline timing](../../experiments/dom-downsampling/compact.js#L205), [check](../../experiments/dom-downsampling/compact.js#L282). Preserve full short alerts, labels, error messages, and state qualifications when practical; require expansion for longer critical text. Record separate original-to-output and post-excerpt-to-output checks. Prefix-only excerpts can remove negation or qualifications anywhere, not only in alerts.

## Smaller but concrete source losses

6. **Keep semantic destination identity while removing tracking.** `data-destination` contains only hostname and pathname, truncated to 96 characters; all query parameters and fragments disappear. A synthetic `href="#apply"` became `/`, and `/search?q=cats` and `/search?q=dogs` both became `/search`. The fragment target ID survives the earlier relationship inventory but the link-to-target edge is gone. This is deliberate descriptive output, yet it weakens navigation grouping and disambiguation. Relevant code: [target collection](../../experiments/dom-downsampling/compact.js#L52), [destination shortening](../../experiments/dom-downsampling/compact.js#L104). Keep a separate short local destination identity or target reference, preserve approved semantic query fields when useful, and strip known tracking fields independently. Full raw URLs are not necessary.

7. **Treat SVG text as reading evidence, and preserve preformatted whitespace when excerpting.** SVG handling deletes all children and selects only the first `title` or `desc` unless an `aria-label` exists. A synthetic chart with a title, description, and two textual values retained only its title in `structure` mode. Strip drawing/path payload while keeping textual labels and descriptions as compact evidence. Separately, text excerpting normalizes text before shortening, including `pre`/`code`/`textarea`, despite skipping these tags in the earlier whitespace-normalization pass. A long multiline code fixture became a single line. Relevant code: [SVG](../../experiments/dom-downsampling/compact.js#L124), [initial whitespace exception](../../experiments/dom-downsampling/compact.js#L144), [excerpt normalization](../../experiments/dom-downsampling/compact.js#L170). Excerpt preformatted text using its original character stream. Code/math ancestor preservation is covered in item 1.

8. **Add semantic retention checks alongside existing provenance checks.** The current tests mostly establish honest partiality, not information needed to organize a page. The form-outline test explicitly expects zero remaining inputs. The namespace/forms test checks that relationships are not dangling, without requiring their preservation. The large-heading/pre test checks shortening and output size, not whitespace. Only native headings, a selected option, checked labels, and alert contexts have positive retention fixtures. Relevant tests: [relationship check](../../experiments/dom-downsampling/test_compact.py#L84), [form omission](../../experiments/dom-downsampling/test_compact.py#L105), [large pre](../../experiments/dom-downsampling/test_compact.py#L123). Add retention assertions for unit boundaries, role headings, control name/state pairs, relationship edges, text-bearing graphics, and qualifiers. Report retention by unit type, not only elements, characters, and a mixed links/controls count. `omittedTextCharacters` counts excerpt shortening, not all text removed by list sampling or folding; the separate exposed-text metric is the better whole-pipeline measure.

The DOM budget remains an element-count target based on the original parsed source, rather than a token or semantic-coverage budget. It is useful for the compression experiment but should not decide which evidence is sufficient for complete hierarchy labels. If training uses the current partial representation, targets must be scoped to that evidence or include an executable, filtered expansion step.
